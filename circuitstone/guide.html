CircuitStone Guide

Controls

  • Left click to place blocks
  • Right click to delete blocks
  • Press Q/E or Scroll to rotate the current block placement.
  • Press Space to pause or resume the simulation
  • Press S to step one tick in the simulation
  • Press keys 1-5 to select a block color (used by wires, power blocks, and lamps)

Components

  • Wire

    Used to connect components together and carry signals.

    1. Red: Doesn't connect with green or blue wire
    2. Green: Doesn't connect with blue or red wire
    3. Blue: Doesn't connect with red or green wire
    4. White: Connects with all type of wire
    5. Black: Only connects to white wires and isn't powered by components

  • Inverter

    Inverts the signal it receives. 1 -> 0, 0 -> 1. Equivalent to a NOT gate.

  • Diode

    Only lets the signal flow one way. Most components do this already, but I wanted to make a dedicated one.

  • Bridge

    Allows wires to cross (directional) without interfering.

  • Switch

    Outputs a signal toggleable by clicking on it.

  • Button

    Outputs a signal when held down.

  • Power Block

    Outputs a constant signal. Follows the same general rules as the wire colors.

  • Delay

    Delays the signal by an adjustable amount.

  • Hover Sensor

    Outputs a signal when the cursor hovers over it.

  • Lamp

    Lights up in it's color when powered from the input side.

  • Toggle

    Toggles it's state when powered. Requires a components like a diode to read.

  • Key Block

    Gets powered it's bound key is pressed. Click to bind a new key. Requires a component like a diode to read.

  • Transmitter

    Sends a global radio signal when powered. Click to increment the channel and shift+click to decrement.

  • Receiver

    Gets powered when it receives a radio signal on it's channel. Click to increment the channel and shift+click to decrement. Requires a component like a diode to read.

  • Random

    When it receives a signal, it has a 50% chance to be on. Requires a component like a diode to read.

  • Trigger

    Outputs a signal for 1 tick when the input turns on. Equivalent to a rising edge detector. Requires a component like a diode to read.

  • Note Block

    Plays a set note when powered. Click to increment the note and shift+click to decrement.

  • Rotator

    Rotates the block in front of it by 90 degrees in a set direction when powered. Click to toggle the direction.

  • Actuator

    Interacts with the block in front of it when powered, as if you clicked it. Click to toggle the mode:

    • Green: Sends a normal click
    • Blue: Sends a shift click

  • Repulsor

    Pushes the block in front of it forward like a piston from an undisclosed open world game.

  • Detector

    Is powered if there is a block in front of it. Requires a component like a diode to read.

  • Duplicator

    Duplicates the block behind it to the position in front of it. Powered from wither side.

  • Comment

    Stores text in it so other people can read it. Can be read by a component if there is text inside.
